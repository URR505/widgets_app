# Widgets Gallery - Flutter Material 3

Una aplicación completa que muestra los diferentes widgets y funcionalidades de Flutter Material 3, implementando las mejores prácticas de desarrollo y patrones de diseño modernos.

## 🚀 Características

- Implementación completa de Material Design 3
- Gestión de estado con Riverpod
- Navegación con GoRouter
- Temas dinámicos y modo oscuro

## 📱 Secciones

1. **Contador con Riverpod**
   - Un contador de clics con riverpod

2. **Botones**
   - Varios botones en Flutter

3. **Tarjetas**
   - Un contenedor estilizado

4. **Progress Indicators**
   - Generales y controlados

5. **Snackbars y diálogos**
   - Indicadores en pantalla

6. **Animated container**
   - Stateful widget animado

7. **UI Controls + Tiles**
   - Una serie de controles de Flutter

8. **Tutorial Introductorio**
   - Pequeño tutorial introductorio

9. **InfiniteScroll y Pull**
   - Listas infinitas y pull to refresh

10. **Theme changer**
    - Cambio dinámico de temas

11. **Random Word**
    - Generador de palabras aleatorias
